# Fanuel Chitiyo Portfolio Starter

## Publish
1. Create a public GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files to the repository root.
3. Replace placeholder email, LinkedIn and GitHub links in `index.html`.
4. Add your approved CV at `documents/Fanuel_Chitiyo_CV.pdf`.
5. Add approved screenshots under `assets/images/` and update project pages.
6. GitHub: Settings → Pages → Deploy from a branch → `main` → `/root` → Save.

Only publish approved, anonymised or demonstration content. Do not include beneficiary data, active operational locations, sensitive mine-action information, confidential reports, passwords or API keys.
